- 기존 100개 원고: `scripts/build-bank.py`. `SKIN-0001`~`SKIN-0100`의 모든 필드를 보존했다. 직렬화한 기존 객체 배열의 SHA256은 `ed3c2d7d49fd61f54a5e51edadce72a4f7a25ab3d589eba25731de31ca25b518`이다.
- 추가 개념형 300개 원고: `scripts/manuscripts/concepts.tsv`. 5영역 × 10단원 × 6문항으로 각 질문·정답·해설을 작성했다. ID는 `SKIN-0101`~`SKIN-0400`이다. 보기는 같은 단원의 대안 용어에서 고정 순서로 구성한다.
- 계산형 600개: `scripts/bank_expansion.py`. ID는 `SKIN-0401`~`SKIN-1000`이다. 명시한 학습용 가정과 고정 조건 조합으로 생성하며 난수를 쓰지 않는다.
- AI 일반 지식으로 자체 작성했으며 외부 교재나 기출 자료를 열람하여 옮기지 않았다. 확인한 출제 연도·회차가 없으므로 모두 null이다.
- Q-Net 공식 종목 페이지는 이전 조사에서 프록시 CONNECT 403으로 차단되어 본문 미열람이다. 이번 은행 확장에서 공식 규칙·현행 출제기준 대조가 완료된 것으로 바꾸지 않았다.
- 민간 문제 사이트를 복제하지 않았다. 외부 기출의 재배포 이용 조건을 확보하지 못하여 원문 기출을 등록하지 않았다.
- 문항 sourceUrl은 이 작성·검토 기록의 저장 위치다. 외부 정답 증빙이나 열람한 교재 목록이 아니다.
- 새 원고와 데이터는 CC BY 4.0으로 제공하며 외부 자료의 권리를 주장하지 않는다.

추가 개념형은 상담·관찰·테크닉·제형·세포·조직·순환·신경·호흡·영양·기기 원리·안전·성분·품질·미생물·소독·환경·보건 통계 등을 다룬다. 질문이 요구하는 개념과 정답을 대조하고, 같은 단원의 다른 보기에도 답이 적용되는 모호한 문구는 수정했다. 예를 들어 여러 보습 성분 모두에 해당할 수 있는 일반적인 진정 효능 질문 대신 해당 성분을 특정하는 생화학적 특징으로 바꿨다. 기존의 유화 정의와 겹치는 질문은 합일에 의한 제형 불안정을 묻도록 변경했다.

개념형 400개가 서로 독립된 400개 전문 분야라는 뜻은 아니다. 전류의 정의와 단위처럼 같은 주제의 서로 다른 확인 사항을 다룬다. 단순히 보기 순서만 바꾼 개념형을 추가하지 않았다. 계산형의 동일 원리 반복은 아래 family로 별도 분류하며 의미상 완전히 새로운 개념으로 세지 않는다.

10개 응용 유형은 곱셈·비례·역수·백분율 등 공식을 공유한다. 서로 독립된 10개 출제 영역 또는 600개 기출이라는 뜻이 아니다. 각 family 안에 고유한 입력 조합 60개가 있으며 family를 빠뜨린 숫자 변형은 없다.

생성은 Python Decimal로 하고, 독립 검증은 `tests/calculations.test.ts`의 TypeScript BigInt 유리수와 정수 나머지 기반 반올림으로 수행했다. 모든 600개에서 공식·입력·단위·정답 번호·수치상 같은 보기의 중복·해설의 결과 표기를 대조했고 역대입으로 보존 관계를 확인했다. 0.625→0.63, 14.325→14.33 등 반올림 경계도 별도로 검사했다. 보기의 수치 순위가 항상 같은 위치에 정답을 드러내지 않도록 네 가지 정렬 순위를 각 150개로 분산했다.

수치 검증과 개념 정확성 검토, 외부 전문가 검수, 공식 출제기준 대조는 서로 다른 절차다. 이 계산 테스트가 공식 출제 적합성이나 특정 제품의 실제 안전성·효능을 입증하지 않는다.

## 중복·보존·검수의 한계

- 고유 ID 1,000 / 정규화 본문과 정렬 보기의 고유 조합 1,000 / 등록 중복 0.
- 숫자형은 10개 family와 family별 60개 입력 조합으로 묶는다. 같은 원리의 숫자 변형을 의미상 독립 개념으로 세지 않는다.
- 기존 100개 객체의 해시 보존 검사가 통과했다. 기존 풀이 기록·북마크·오답 참조는 그대로 사용할 수 있다.
- 해설 문장과 정답은 작성 과정의 내부 대조 검토다. 독립적인 제3자 검토나 외부 전문가 검수는 수행하지 않았다.
- 법령의 현행 수치·신고 기준·제품별 안전 조건을 만들어 넣지 않았으며 공식 출제기준 전 범위와 실제 난이도를 보장하지 않는다.
- 기본 은행은 내부 검토 등록 1,000 / 검증 대기 0 / 개인 로컬 등록 제외 / 기출 0 / 복원 0 / 목표 부족 0이다. 수량 충족과 공식 규칙·전문가 검증 완료를 혼동하지 않는다.
