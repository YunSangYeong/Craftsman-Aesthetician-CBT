# 미용사(피부) 필기 CBT

전기기능사 CBT의 React·TypeScript·Vite 앱을 재사용한 비공식 학습 사이트입니다. 로그인·서버·유료 API 없이 브라우저에 학습 기록을 저장합니다.

**목표 1,000문항 중 현재 내부 검토 문항 100개이며 900개 부족합니다. 공식 시험 규칙 대조와 외부 전문가 검수는 미완료입니다. 최종 표준 충족으로 표시하지 않습니다.**

- 표준: `cbt-site-standard` v1.4.0, 원본 최신 main `76b990b8720adfa85c22a0a8f699b17094aa357b`.
- 재사용 앱: `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`. 전체 표준 폴더를 복사했으며 [AGENTS.md](AGENTS.md)로 연결합니다. 기존 AGENTS.md는 없었습니다.
- 이름·영역·시간·문항 수·합격선·자료 ID·배포 경로는 [qualification.json](src/qualification.json)에서 관리합니다. 전기기능사 문제 데이터는 포함하지 않습니다.

## 기능

실전 모의시험, 랜덤 문제풀이, 오답 복습, 북마크, 학습 통계, JSON·CSV 등록과 검수 승인, 검색·페이지 목록·내보내기, 기록 백업·확인 후 초기화를 제공합니다. 가져온 문제는 로컬 검증 대기 상태로 저장되며 GitHub 공용 문제은행에 자동 게시되지 않습니다.

학습 기준·자료 버전 선택 메뉴는 없습니다. 실전은 답안 선택 후, 랜덤은 채점 후 Space로 다음 문제에 이동합니다. 포커스·길게 누르기·수정키·미응답·대화상자·폼 입력 보호와 마지막 시험 문제 자동 제출 방지를 포함합니다.

실전 답안은 즉시 저장되고, 절대 종료 시각으로 남은 시간을 계산하며 만료 시 자동 제출합니다. 실전 중 정답·해설을 숨기고 제출 후 전체 보기·해설·출처·오답만 다시 풀기를 제공합니다. 모바일 고정 메뉴는 독립 스크롤과 동적 높이를 사용합니다. 상단 상시 면책 배너는 없으며 출처와 한계는 문제은행 관리·해설·문서에 둡니다. 저장 실패·손상 경고는 유지합니다.

## 시험 설정과 공식 확인 상태

현재 **잠정 학습 설정**은 총 60문항·60분·4지선다·100점 환산·60점 이상 합격·과락 미적용입니다. 미응답은 오답입니다. 35개 정답(58.3점)은 불합격, 36개 정답(60점)은 합격으로 계산합니다. 표시는 소수 첫째 자리로 반올림하지만 판정은 원비율로 합니다.

학습 영역은 피부미용학 / 피부학 및 해부생리학 / 피부미용기기학 / 화장품학 / 공중위생관리학의 5개입니다. 영역별 고정 출제 수는 강제하지 않고 검수 완료 전체 풀에서 60개를 무작위 추출합니다. 공식 과목 명칭·현행 범위·분포를 재현했다고 주장하지 않습니다.

2026-10-26 [Q-Net 종목 정보](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7974)를 직접 열려고 했으나 `curl: (56) CONNECT tunnel failed, response 403`, HTTP `000`으로 차단되어 본문을 읽지 못했습니다. 위 수치와 영역은 AI의 일반 지식에 따른 잠정 학습 설정입니다. 공식 시험 규칙·과목·시간·배점·합격·과락과 현행 출제기준의 독립 대조는 남아 있습니다. 접근하지 못한 공식 자료를 문항의 정답 근거로 인용하지 않습니다.

## 문제은행

| 학습 영역 | 자체 제작 개념형 | 원문 기출 | 복원 | 숫자 변형 |
| --- | ---: | ---: | ---: | ---: |
| 피부미용학 | 20 | 0 | 0 | 0 |
| 피부학 및 해부생리학 | 20 | 0 | 0 | 0 |
| 피부미용기기학 | 20 | 0 | 0 | 0 |
| 화장품학 | 20 | 0 | 0 | 0 |
| 공중위생관리학 | 20 | 0 | 0 | 0 |
| 합계 | **100** | **0** | **0** | **0** |

검증 대기 기본 문항 0·제외 중복 0·등록 고유 ID 100·정규화 본문/보기 고유 100. 개인 등록 문항은 이 수에 포함하지 않습니다. 숫자 변형 family 0, 조건 조합 0이며 100개 문항을 1,000개 독립 유형으로 부풀리지 않습니다. 관련 개념이 겹치는 문항은 있으므로 100개 모두가 서로 독립된 전문 지식 영역이라는 뜻도 아닙니다.

모두 AI의 일반 지식으로 자체 작성했습니다. 문장·정답·보기의 내부 대조 검토이며 외부 자료 대조·독립 전문가 검수는 아닙니다. 난이도는 기초(하)이며 실제 시험 난이도·전 범위·법규 최신성은 보증하지 않습니다. 법령 수치·치료 프로토콜은 만들어 넣지 않았습니다. [문항 검토 기록](docs/question-review.md)에 범위를 기록했습니다.

기출 원문·정답·회차·재배포 허용을 확보하지 못하여 기출을 싣지 않았습니다. 민간 사이트의 문제를 복제하지 않았고 연도·회차는 모두 null입니다. 문항의 저장소 링크는 작성 위치·검토 기록이며 외부 정답 증빙이 아닙니다. 새 문항과 원고는 CC BY 4.0, 재사용 앱은 MIT입니다. [LICENSE](LICENSE)를 보존·추가했습니다. 외부 자료의 권리를 대신 부여하지 않습니다.

## 개발과 검증

Node.js 24.19.0 (최소 22.12.0)과 npm을 사용합니다. 별도 서비스나 비밀키는 필요 없습니다.

```bash
cd /workspace/Craftsman-Aesthetician-CBT
npm ci --cache /tmp/skin-npm-cache --no-audit --no-fund
npm run dev
# 검증
npm test
npm run build
# 이 클라우드에는 /usr/bin/chromium이 설치되어 있음
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
# 별도 Chromium이 없다면 Playwright 공식 브라우저 설치 후 실행
npx playwright install --with-deps chromium
npm run test:e2e
```

데이터는 `python3 scripts/build-bank.py`로 동일하게 재생성됩니다. 문항 ID `SKIN-0001`~`SKIN-0100`과 등록 순서는 고정이며 난수·외부 다운로드를 쓰지 않습니다. 기존 문항을 확대할 때 ID와 학습 기록 참조를 보존해야 합니다.

[실제 검증 결과](docs/validation.md)는 로컬 검사·원격 반영·CI·배포·공개 화면 확인을 구별합니다. Playwright는 PC와 Pixel 7 에뮬레이션으로 실행합니다. 실기기·Safari·Firefox 검증은 미실행입니다.

## 기록과 보존

저장 키는 `craftsman-aesthetician-cbt:v1`이며 다른 자격증의 기록과 분리됩니다. 최근 응답 5,000개와 시험 30회, 진행 시험·연습·오답·북마크·로컬 등록 문제를 저장합니다. 통계는 보존된 응답 기준이며 전체 평생 기록은 아닙니다. 초기화는 기본 문제를 지우지 않습니다. JSON 백업 내보내기는 있으며 UI 복원 기능은 없습니다. 손상 원본은 자동 덮어쓰지 않고 원본 백업을 제공합니다. 시크릿 모드·iframe·브라우저 설정에 따라 저장이 제한될 수 있습니다.
